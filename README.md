# Emmanuel Siamoonga: Portfolio (React + Vite)

## Run locally
    npm install
    npm run dev        # opens at http://localhost:5173

## Your photo
Copy your photo to `public/image/emmanuel.jpeg` (same file name as before).

## Edit content
Everything (text, projects, skills, contacts) is in `src/data.js`.
To add a project, copy one block in the `projects` array.

## Deploy
    npm run build      # output goes to dist/
Upload `dist/` to Netlify (drag and drop), or connect the repo to Vercel / GitHub Pages.
